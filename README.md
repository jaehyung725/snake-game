# 지렁이 게임

출처: https://github.com/code69b-lab/snakegame

원본 main 브랜치의 index.html을 그대로 사용합니다. 원본 Git blob: 18c1f816e823a403640e32de66ffc89fdcddc2c9.

## 실행과 조작
- index.html을 Chrome 또는 Edge로 엽니다. 별도 설치나 외부 API는 필요하지 않습니다.
- 게임 시작 버튼 또는 Space / Enter로 시작합니다.
- 방향키, WASD 또는 화면 방향 버튼으로 움직입니다.
- 먹이를 먹으면 10점을 얻고 길이가 늘어나며 속도가 조금씩 빨라집니다.
- 벽이나 몸에 부딪히면 종료됩니다. 다시 도전 버튼으로 재시작합니다.
- 최고 점수는 현재 브라우저의 로컬 저장소에 보관합니다.
- 이 버전에는 일시정지, 난이도 선택, 워프, 효과음 기능이 없습니다.

## 로컬 파일
- index.html: 원본 게임 (CSS와 JavaScript 포함)
- README.md: 현재 설명과 원본 출처
- .gitignore: 로컬 비밀정보·개인자료·백업 제외 규칙
- ../backup-intro/: 상위 폴더로 옮긴 이전 소개 페이지와 README 백업. 현재 프로젝트 폴더 밖에 있으며 업로드 대상에서 제외합니다.

## 업로드 준비
- 업로드 후보는 index.html, README.md, .gitignore 세 파일입니다.
- 계정, 대상 저장소와 public/private 범위를 직접 확인한 후 업로드합니다.
- 비밀번호, 토큰, 인증 코드, 비밀 설정, 개인자료와 백업은 올리지 않습니다.
- .gitignore는 모든 비밀정보를 자동 탐지하지 않으며 이미 추적 중인 파일을 자동으로 제거하지 않습니다.
- 웹 업로드에서는 .gitignore에 의존하지 말고 후보 세 파일만 직접 선택합니다.
- 기존 저장소에 같은 이름의 파일이 있으면 먼저 내용을 비교합니다.
- Pages 공개는 저장소 업로드와 별도로 선택합니다.
