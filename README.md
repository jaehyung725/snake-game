# 지렁이 게임

## 로컬 실행

1. 이 폴더의 `index.html`을 Chrome 또는 Edge로 엽니다.
2. `게임 시작` 버튼 또는 Space / Enter를 누릅니다.
3. 방향키(↑ ↓ ← →), WASD, 화면 방향 버튼으로 조작합니다.
4. 종료 후 `다시 도전`을 누르면 새 게임을 시작합니다.

HTML·CSS·JavaScript가 index.html 하나에 포함되어 있습니다. 별도 패키지, 로그인, 외부 API는 사용하지 않습니다.

## 구현된 기능

- 어두운 배경, 파란 지렁이, 빨간 먹이
- 먹이당 10점, 길이 1칸 증가
- 먹이 섭취 시 이동 간격 130ms에서 2ms씩 감소(최소 60ms)
- 벽 또는 몸에 부딪히면 종료
- 현재 점수와 최고 점수 표시
- 최고 점수를 브라우저 localStorage에 저장
- 재시작 시 점수 0점·길이 3칸·초기 속도로 복구, 최고 점수 유지

원본과 동일하게 일시정지, 난이도 선택, 워프, 효과음은 없습니다. 게임판은 원본의 고정 400×400 크기를 유지하므로 좁은 화면에서는 가로 스크롤이 생길 수 있습니다.
