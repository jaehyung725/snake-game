# 지렁이 게임

## 🌐 1. 웹 브라우저에서 플레이하기 (설치 불필요)

- **온라인 바로 접속**: [https://jaehyung725.github.io/snake-game/](https://jaehyung725.github.io/snake-game/)
- 또는 로컬에서 `index.html` 파일을 더블 클릭하여 실행할 수 있습니다.
- **조작**: 방향키(`↑`, `↓`, `←`, `→`) 또는 `W`, `A`, `S`, `D` / 화면 가상 버튼 터치
- **시작**: `게임 시작` 버튼 또는 Space / Enter
- **재시작**: 게임 종료 후 `다시 도전` 버튼

HTML·CSS·JavaScript가 index.html 하나에 포함되어 있습니다. 별도 패키지, 로그인, 외부 API는 사용하지 않습니다.

## 구현된 기능

- 어두운 배경, 파란 지렁이, 빨간 먹이
- 먹이당 10점, 길이 1칸 증가
- 먹이 섭취 시 이동 간격 130ms에서 2ms씩 감소(최소 60ms)
- 벽 또는 몸에 부딪히면 종료
- 현재 점수와 최고 점수 표시
- 최고 점수를 브라우저 localStorage에 저장
- 재시작 시 점수 0점·길이 3칸·초기 속도로 복구, 최고 점수 유지

일시정지, 난이도 선택, 워프, 효과음은 없습니다. 게임판은 고정 400×400 크기이므로 좁은 화면에서는 가로 스크롤이 생길 수 있습니다.

## 검증 결과

- 공개 HTTPS 주소에서 게임 화면 표시, 게임 시작, 화면 방향 버튼 이동 확인(2026-11-17).
- 실제 로컬 브라우저: 화면 표시, 시작, 화면 방향 버튼 이동, A 키 이동, 벽 충돌 종료, 재시작 확인.
- 분리된 JavaScript 실행 검사: 먹이당 +10점, 길이 증가, 속도 증가, 벽·몸 충돌, 역방향 전환 방지, WASD 입력, 최고 기록 저장 호출, 재시작 초기화와 최고 기록 유지 통과.
- 이번 브라우저 조작에서 먹이 섭취와 0점보다 높은 최고 기록의 새로고침 후 유지는 미확인입니다. 위 규칙 검사는 브라우저 실조작을 대신한 것으로 표시하지 않습니다.
- 모바일 실기기와 전체 칸을 채웠을 때의 동작은 미확인입니다.

## 파일과 백업

- index.html: 실행 파일
- README.md: 실행 안내와 검증 결과
- .gitignore: 비밀정보·개인자료·백업 제외 규칙
- backups/before-local-review-20261117-111454/: 이번 작업 전 세 파일의 백업
- ../backup-intro/: 상위 폴더의 이전 소개 페이지 백업(보존)

백업과 .env, 인증키, 개인자료, 로그 등은 업로드 대상에서 제외합니다. .gitignore는 모든 비밀정보를 자동 탐지하지 않으며, 웹 업로드 시에는 올릴 파일을 직접 선택해야 합니다.
